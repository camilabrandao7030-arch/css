explicação sobre Flexbox:

Conceito Explicação
CSS É a linguagem usada para estilizar páginas HTML, definindo cores, tamanhos, espaçamentos e organização visual dos elementos.
Funcionamento O CSS funciona através de seletores, propriedades e valores, permitindo alterar a aparência dos elementos de forma simples e organizada.

Resumo de Flexbox

Propriedade Explicação
display: flex Ativa o Flexbox e permite organizar os elementos de forma flexível dentro de um container.
Alinhamento Com justify-content e align-items é possível alinhar os elementos horizontalmente e verticalmente com facilidade.
